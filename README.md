  <h1>Sp Scoreboard</h1>
  <p>Advanced, Lightweight, and Comprehensive FiveM Scoreboard Script for ESX & QBCore.</p>
</div>

<br>

> **Description:**

* FiveM Script Sp_Scoreboard It comes with a modern NUI, Discord avatars, and many nice features. The script helps you and your players to get a good overview of online players, jobs, and live statistics.

> **Features:**

* Supports both **ESX** and **QBCore** Frameworks.
* Built-in Standalone VIP System (Saves automatically without database/SQL dependencies via KVP).
* Built-in server commands for admins to manage VIPs (`/givevip` and `/removevip`).
* Automatic Discord Avatar integration (Requires Badger_Discord_API).
* Interactive filtering system to display players easily by jobs.
* Special Tags/Colors/Icons for Staff (Admin, Mod, Founder) and VIP members.
* Live Player Ping indicators (Good/Medium/High signal bars).
* Live Playtime tracking for every player.
* High performance and well-optimized code.
* Highly customizable HTML & CSS structure.
* Easily toggleable "Dummy Players" system in the config for content creators/script showcases.
* You can display every possible job and its active count.
* Low ms (0.00-0.01) ms.
* and much more!

> **Requirements:**

* `es_extended` (Legacy / 1.2 / 1.1) **OR** `qb-core`
* `Badger_Discord_API` (Optional, only needed for Discord avatars)

> **Installation:**

1. Download the latest version from GitHub.
2. Put the `Sp_scoreboard` folder inside your `resources` folder.
3. Edit the `config.lua` file to match your framework, server name, slots, and preferred colors/jobs.
4. Add `ensure Sp_scoreboard` to your `server.cfg` file.
5. Enjoy the beautiful user interface!

> **Keybindings:**

* **F10:** Toggle Scoreboard (can be changed in `client/main.lua` and Config)
* **Escape:** Close Scoreboard (also supports F10 while NUI is active)

> **Commands:**

* `/givevip [id]` - Gives a player standalone permanent VIP Status (Admin/Console only).
* `/removevip [id]` - Removes VIP Status from a player (Admin/Console only).
